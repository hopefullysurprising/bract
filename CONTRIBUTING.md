# Contributing

Thanks for trying bract! Feedback is genuinely welcome — it's how the tool gets better.

## Bugs, ideas, questions

- **Bug?** Open an [issue](https://github.com/hopefullysurprising/bract/issues/new/choose) with the Bug report form.
- **Idea or feature request?** Open an issue with the Feature request form.
- **Question, help, or something open-ended?** Start a [discussion](https://github.com/hopefullysurprising/bract/discussions).

## Code contributions

bract follows an opinionated roadmap, so I'm not actively seeking code
contributions right now. A small PR for an obvious bug fix is welcome; for
anything larger, please open a discussion first so we can talk it through before
you spend time on it.
